# Security Policy

## Supported Versions

Only the latest release version is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v2.0.x  | :white_check_mark: |
| < v2.0  | :x:                |

## Reporting a Vulnerability

We take the security of AVI Core seriously. If you find any security vulnerabilities, please do **not** open a public issue. Instead, report it privately to the maintainers.

Please send security vulnerability disclosures to:
* **Email**: sahilsawant182@gmail.com

Please include detailed instructions, logs, or proof of concepts to help us reproduce and address the issue quickly. We will acknowledge receipt of your report within 48 hours and work with you to resolve it.
